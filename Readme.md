# Linux Process Inspector & Monitor

A C-based system utility designed to inspect active Linux processes and monitor system RAM.

## Features
- Displays system RAM allocation.
- Inspects top active processes.

## How to Build and Run
```bash
gcc main.c -o process_inspector
./process_inspector
